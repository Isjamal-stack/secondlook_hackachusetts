# Kiro Configuration

This directory contains Kiro IDE configuration for the SecondLook project.

## Contents

### Steering Files (`steering/`)
Steering files provide context and guidelines for AI-assisted development:

- **project-context.md** - Architecture, setup, and development workflow
- **ai-guidelines.md** - Information about AI integration and output formatting

These files are automatically included to give Kiro context about the project.

## Hooks (`hooks/`)
Hooks automate workflows at key points in development:

- **validate-before-commit.json** - Pre-task validation checklist

## Usage

### For Team Members
These configurations are shared across the team to ensure:
- Consistent development practices
- Better AI-assisted coding with proper context
- Automated workflow reminders

### Modifying Configuration
- **Steering files**: Edit markdown files to update project context
- **Hooks**: Use Kiro's Hook UI or edit JSON files directly
